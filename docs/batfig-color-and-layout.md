# BatFig 配色、透明图底与坐标轴对齐

2026-10-13。本轮在现有 Matplotlib 可编辑图与 React 画布上修复配色写入和交互性能，增强背景、对齐与网格控件。沿用 AGPL-3.0-only、现有保存/重放协议和严格 Arial / Times New Roman 字体检查。本文记录功能范围；本机科研数据、截图、日志与产物仅保存在忽略的 `codex-files/`。

## 白色页面与透明图底

- 新画布使用显式白色、不透明页面。新加入的图，在后端确认 `editable` 且有源脚本时，默认去除 Figure 外底和二维坐标区底色；运行时捕获的可编辑图也使用该默认值。白纸和透明图底是两个独立设置。
- 选择可编辑面板后，属性栏的“图片背景透明”可以统一切换外底与二维坐标区底色，修改可撤销、保存和重放。已有文档不会因打开而自动改变背景；素材已写回的明确背景覆盖也保留。
- 有脚本路径不等于可编辑。`source_missing`、`layout_only` 和尚无 capability 事实的素材不自动注入透明覆盖，避免仅为默认背景触发失败的脚本渲染。
- 本功能不从普通 PNG/JPEG/PDF 的像素中抠白。位图内烘焙的背景保持原样。二维坐标区透明不改动 3D 的 x/y/z 背景面板；3D 仍使用已有专属面板属性。

## 热图与 DIY 色条

热图和关联色条可能各自留有历史 `cmap` 覆盖，旧的窄范围覆盖会盖住从色条提交的新配色。本轮按 manifest 的色条、mappable 与共享色阶关系收齐传递别名，清除竞争写入，并优先通过可写色条同步同组图元。不会仅凭两个色图同名就把它们合并。独立色阶继续独立。

图像与 QuadMesh 热图的颜色映射控件放在属性首屏。在颜色映射选择器中打开“DIY 热图配色”，可设置 **3–32 个颜色点**，调整各点位置、增加/移除点、反转色序或均匀分布，再点击“应用配色”。位置必须严格递增，首尾为 0% 和 100%；非法颜色或位置明确报错。取消不改文档；应用产生一次可撤销修改。

DIY 定义使用颜色数组与位置数组保存，而不是依赖进程里的临时色图名称。Matplotlib 图像、QuadMesh/Collection 与可编辑色条共用解码器；保存重开和冷重放能恢复同一份定义。重复选择已生效配色不额外增加历史或请求渲染。原脚本与目标相同的内置色图只有在当前精确渲染事实确认时才短路；脚本自定义色图即使也叫 `viridis`，仍可替换成真正的内置 `viridis`。

通用取色入口增加常用色块和分类/发散配色组合，DIY 编辑器复用同一份色样。当前包括经典、对比、柔和、蓝白红、蓝金及紫绿组合。它们是编辑起点，不代表任意数据都适用；DIY 色图的感知均匀性未获自动认证，仍保留 `palette-semantic` 预检提示。

## 取色交互与撤销粒度

连续拖动取色滑块时，颜色先留在本地草稿。具备 SVG 预览能力的字段按动画帧预览；该过程不逐次写文档、不触发自动保存，也不逐次请求 Matplotlib。完成取色、失焦或显式结束手势后只提交最终值，形成一次撤销。Esc / pointercancel 取消草稿并恢复预览。

切换编辑对象会取消旧目标草稿，迟到的原生取色事件不能写到新对象。切换文档或画布、保存等需要收尾的操作，会先结算当前输入。没有 SVG 预览能力的字段显示色块草稿，完成后交给后端渲染；不把局部预览当作导出或几何权威。大规模 SVG 样式账本改用 Set 去重，避免连续预览重复扫描已经登记的节点。

## 对齐与网格

多选后的排列入口提供“坐标轴 / 图片边界”基准，默认“坐标轴”；属性栏、浮动栏及右键菜单共用同一设置。位置对齐和水平/垂直分布使用所选基准，等宽/等高仍调整整张图片尺寸。

坐标轴基准使用当前面板变体的精确 manifest，排除色条轴与隐藏轴；双 Y 轴自然共享坐标区，多子图面板以可见坐标区的联合边界参与对齐。裁剪、翻转和旋转后的页面坐标纳入计算。仅移动画布面板，不改图内数据、轴范围或内部覆盖。锁定对象可作参照但不移动。

几何未准备好时整次对齐等待，不拿旧预览猜轴线；点击“读取坐标轴”后才请求准备，不会仅因选中对象就执行用户脚本。确认只有排版能力的素材、没有可见坐标区的图，以及画布文字/标注使用对象边界，界面说明此行为。未知或缺少源脚本的素材可显式改用“图片边界”。当前没有提供多子图面板内部逐轴配对或自动匹配左右坐标轴的功能。

新用户的默认网格间距为 **2 mm**。画布属性中直接显示网格开关、0.5–50 mm 间距输入与 1/2/5/10 mm 预设。已有本机网格偏好保持原值；间距越小越密。网格是辅助显示和吸附偏好，不进入导出或文档撤销历史。对齐基准是当前会话状态，不写入科学数据或文档内容。
