# Ctrl 多选与独立色标

按住 Ctrl 依次点击 a、b、c 等画布文字，可追加选中；再次点击一个已选项取消它。
松开 Ctrl 后可统一修改字体、字号或拖动，已有撤销／重做、保存和重开流程继续使用。
Command（macOS）和 Shift 也可加选；图层列表、图内元素列表及框选使用同一判据。
混合类型选择和成组对象规则保留，选择本身不产生历史或未保存修改。

Ctrl 起手用于加选；需要拖动时临时关闭吸附或只移动容器自身，先开始拖动，再按 Ctrl。
修饰键双击不会意外打开文字编辑；图内边框加选不会修改刻度。

画布的坐标轴对齐和统一拼版继续排除色标。图内对齐也排除独立色标，
色标仍可单独编辑、拖动与缩放。显式选择“图片边界”时沿用完整图片外框；
色标在图片里占用的空间仍用于避免拼版溢出，不作为主坐标轴对齐的参照。
