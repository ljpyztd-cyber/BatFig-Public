# BatFig 整画布统一拼版

## 坐标轴字号（2026-10-22）

默认把可编辑小图的主横纵轴刻度数字、轴标题统一为最终页面 **8 pt**。用户试用 12 pt 后选择缩小，当前默认以 8 pt 为准；顶部「统一拼版」中的 **轴文字字号** 可以改为 10 pt 等值，点击「应用到整张画布」生效。双 Y 轴也参加统一，科学计数的乘数/偏移文字随刻度字号同步；字体族、字重、内容和数据不变。a–i 编号仍为 Arial 20 pt 常规，色标、图例、一般注释的字号保持独立。

字号按每张图最终的等比缩放换算为脚本字号，随后真实渲染并核对 manifest，不能用请求值代替结果。源字号字段有能力范围，换算后超界或对象锁定时整次拒绝，不静默限幅。源码字号按现有精度保留两位小数，成品有相应的微小量化误差。

变大后的文字可能超过原图边距。系统检查真实文字边界；仅在发生越界且普通二维自动比例轴支持重排时，保留轴框比例并平移/缩小主框，右侧色标和顶部图例随框调整。不会更改 Figure 物理尺寸、拉伸文字、自动换行或裁掉标题。重新渲染、重算最终字号和边界，全部通过才一次提交；无法容纳、显式文字裁剪、手动定位或不支持的约束布局明确报错。科学计数 offset 文字的字号已覆盖，但其独立边距暂未进入 manifest，不能声称自动留边距覆盖该部分。

字号设置、图内覆盖、自动边距、画布布局和编号同次撤销/重做并保存。旧文档打开不会自动改字号；图片模式对已知可编辑图也统一轴字号，纯静态图片仅排列。未知图内能力需要显式读取当前几何。连续比例/间距切换保留最初轴框基线，不能把自动边距位置累计写回基线。这里的字号统一仍不等于图例、注释和投稿要求全部合格。

编号按精确轴文字边界避让：先把同列编号一起向左移动最小必要距离，空间不足时再尝试同行一起向上移动。已有独立刻度文字边界时，不把刻度组之间的空白算作碰撞；位移按整个文字框计算，保留 0.3 mm 间隙。不能越过前列／前行的完整图幅或页面边缘，无法安全完成时整次拒绝。此检测针对可测量的未旋转、未翻转、未裁剪面板中的主轴文字，不覆盖一般画布注释与任意图形。重复应用相同设置不产生额外撤销记录。

## 入口与操作

顶部工具栏的 **统一拼版** 打开画布设置，**整画布网格拼图** 位于设置首屏。无需逐张选择图片，点击 **应用到整张画布** 即按当前设置排列全部可见面板。

新布局的默认设置如下；已有保存设置优先使用保存值。

| 设置 | 默认值与含义 |
|---|---|
| 列数 | `ceil(sqrt(n))`，`n` 为可见图片数；9 张图默认 3 列，编号和其他文字不计入 |
| 单元格比例 | 4:3；坐标轴模式下也是支持重排的主绘图区比例。图片模式保持整图原始比例 |
| 轴文字字号 | 成品 8 pt；主轴标题与刻度统一，可显式改为 10 pt 等值 |
| 横竖间距 | 统一 3 mm，指相邻列／行的完整图幅包络之间的间距 |
| 画布边距 | 8 mm；网格居中，比例限制产生的剩余空间可能使实际外边距更大 |
| 对齐边界 | 主坐标轴框线；色标、外置图例、轴标题与刻度文字不扩大对齐边界 |
| 同列对齐 | 左边界；在坐标轴模式下，同列图片的左轴线对齐 |
| 同行对齐 | 下边界；在坐标轴模式下，同行图片的下轴线对齐 |

**3 mm 不是每一对坐标轴或数据墨迹之间的固定距离。** 每列／行按完整图幅的最大占地排列，较小图片自身的留白仍会保留。2026-10-22 间距调整取消了原先每个单元格内额外的居中空余，按列／行包络紧排后将整组居中；完整图片互不重叠，不裁切空白，不改变图内覆盖或对齐参照。4:3 仍用于初始拟合及支持重排的主轴框比例，紧排后的实际槽宽高随该列／行的图幅占地变化。

2026-10-22：坐标轴模式先由 Matplotlib 重排主绘图区，再按主框尺寸统一缩放。d/g 等普通二维图因此可以同宽、左右框线对齐，e/f 可以同高、上下框线对齐。右侧竖色标保留宽度及与主框的间距、跟随主框高度；轴坐标锚定的上方图例继续留在框外。色标和图例仍是原图内可编辑的独立对象，不计入主轴框，但完整图幅参与统一留空间，不让某一张热图单独缩小。

这次调整写入轴位置覆盖，不拉伸文字或修改数据、字体、Figure 物理尺寸。只在当前精确几何确认是可重排的二维自动比例轴框时应用；候选图真实渲染、轴框比例验证通过后才整次提交。期间有新的编辑、切换文档或项目时取消本次排版。固定数据比例（如饼图）、3D、复杂多轴、裁剪旋转及不支持的手动标注保持原形，并提示保留数量。

- **单元比例**提供 1:1、4:3、3:2、16:9，点击即应用。
- **间距预设**提供 2、3、4、6 mm，点击即应用，横竖使用同一值；其他间距可直接输入。
- **对齐边界**可直接切换坐标轴或图片边界；同列支持左／中／右，同行支持上／中／下，点击即应用。
- **列数、横竖间距和画布边距**支持数值输入。数值先保留为当前控件草稿，再点击 **应用到整张画布**；点击快捷选项也会带上已输入的数值一起应用。

快捷选择作用于当前整张画布，包括已有布局。打开入口本身只查看设置，不自动改动排版；切换画布或撤销至另一套设置时，旧控件草稿不会带入新的画布状态。

## 撤销、编号与保存

一次应用通过同一文档事务保存布局设置、排列顺序、图片位置和尺寸，以及可安全跟随的面板编号位置。**撤销一次**恢复整次操作，重做重新应用。首次按图片高度与竖向重叠识别行，再按行内从左到右记录阅读顺序；不会仅因热图上边距比邻图多几毫米而换行。后续改变比例或间距继续沿用该顺序。对重叠、嵌套等自由布局，仍需检查首次识别结果。

2026-10-22：统一拼版默认将绑定的编号放在单元格左上角的共同位置（向右 1.5 mm、向下 1 mm），因此同列左对齐、同行顶对齐，不再继承各张图片不同的旧编号偏移。图片仍按主坐标轴框线对齐；例如 d 图旁边的色标和 f 图上方的图例只随图片保留，不参与主轴边界计算。在已经应用的网格上新增编号也使用这些位置；尚未应用的布局计划不会提前移动新编号。

旧文档中的简单字母编号仅在邻近图片对应关系唯一时补充绑定。编号保持文字、字号和自身尺寸；锁定、固定、成组、隐藏、归属含糊，或尺寸大到无法在共同位置放入单元格的编号保持原位，需要人工检查。旋转的已绑定编号继续随图片保留相对位置，不强制转正。此功能不会凭空生成缺失编号，也不会把一般文字猜作面板编号。

使用顶部 **保存** 或 `Ctrl+S` 保存文档后，图片几何、编号绑定、布局设置和排列顺序可随文档重开。旧项目缺少网格拼版设置时仍保留原有位置，不能仅因打开项目就自动重排。此功能沿用现有文档保存与导出链，不另建一套项目模型。

支持重排的图在 `panelGrid.frames` 中保存首次输入覆盖与最近一次排版覆盖。比例来回切换从同一基线真实渲染，不逐次缩小绘图区；保存重开继续使用。手工改动图内属性、替换来源或改变原生图幅后重新建立基线，避免覆盖新的用户编辑。画布移动与等比缩放不使基线失效。

编辑器网格默认开启，间距为 **2 mm**，可在画布设置中调整。它是编辑辅助线，不是上面的 3 mm 拼图间距，也不进入 PDF／PNG 导出；显示偏好与文档内容分开保存。

## 明确的边界

- 坐标轴模式只采用当前面板变体的精确 manifest。数据尚未就绪时提示 **读取坐标轴**，须由用户显式触发；旧 SVG 可以显示，但其过期几何不能用来猜测新布局。也可以直接切换为图片边界。
- 明确为静态且没有坐标轴的素材使用图片外框；未知素材状态不会被当作“已知没有坐标轴”。
- 可见图片中存在锁定、固定于布局或成组的面板时，阻止整次拼版，不先改动其中一部分。需解除对应限制后重试。
- 画布扣除边距和间距后空间不足，或设置及几何无效时，明确提示并保持原布局。可以减小边距／间距、修改列数或增大画布。
- 等比缩小图片会缩小图内文字在成品中的实际字号。拼版成功不是字体大小、图例遮挡或投稿要求合格的证明，仍需预检与最终人工视觉检查。
